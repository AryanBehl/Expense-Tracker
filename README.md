# 💰 Expense Tracker

A simple and powerful **Expense Tracker Web App** built using **HTML, CSS, and JavaScript**.
It helps users manage their income and expenses, track balance, and store data locally in the browser.

---

## 🚀 Features

* ➕ Add income & expenses
* 🧾 Transaction history
* ❌ Delete transactions
* 💰 Automatic balance calculation
* 📊 Separate income & expense tracking
* 💾 Data stored using Local Storage (no data loss on refresh)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API

## ⚙️ How It Works

* User adds a transaction (income or expense)
* Data is stored in browser using Local Storage
* App automatically updates balance, income, and expense
* User can delete any transaction anytime
